Why it costs less

Only two parts are second-hand

A used machine is cheap because everything in it is old. Ours isn't. We buy the CPU and GPU second-hand — the two parts where the saving is real — and build the rest of the machine new.

New in every build

  • Motherboard, RAM and NVMe SSD
  • Power supply, cooler and case
  • Fans, cabling and Windows install

Tested second-hand

  • CPU — checked under sustained load
  • GPU — checked for artefacts, thermals and fans
  • Tested, cleaned and serviced before it goes in

That's the difference between us and a flipper: a flipper sells you a whole used machine. You're buying a new machine with two carefully chosen used parts in it — and it looks the part, because the case is new too.

Questions

The things people ask first

Is a used GPU safe to buy?

It depends on which one. We test every card for artefacts under load, check the fans and thermals, and give it a clean and service before it goes in. If a card doesn't pass, we don't sell it — that's why we buy them one at a time instead of by the pallet.

What if something fails?

Every build is burned in before handover, so most faults surface before the machine reaches you. If a part fails afterwards, talk to us — we'd rather fix it than argue about it.

Can I change the parts?

Yes. Different case, more storage, RGB, a bigger GPU — the three tiers are starting points. Tell us the budget and we'll tell you honestly what it buys.

Do you do repairs and upgrades?

Yes — cleaning, re-pasting, storage upgrades, GPU swaps, and diagnosing machines that won't boot. Same workshop, same people.
